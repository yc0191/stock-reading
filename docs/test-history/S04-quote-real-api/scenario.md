# S04 시세 조회 실제 API: 사양

시세 제공자의 **실제 운영 서버**에 현재가 조회를 초당 n회로 보내, 호출 한도가 어느 속도에서 걸리는지와 그 속도를 얼마나 오래 유지할 수 있는지 기록합니다. S03(가짜 서버)이 알 수 없는 제공자 쪽 한도를 봅니다. 외부 서버에 영향이 있어 읽기 전용 호출(토큰 발급, 현재가)만 보내고, 숫자 비교보다 "어느 속도에서 멈췄는지"를 기록합니다.

## 사양
- **도구**: `scripts/live_probe.py`가 `BrokerRateProbeTest`를 실행합니다. 키는 Parameter Store에서 읽어 환경변수로만 넘기고, 손으로 `gradlew`를 돌리면 시험이 건너뜁니다.
- **입력**: 한 종목의 현재가를 같은 속도로 반복 조회합니다. 토큰은 한 번 발급해 재사용합니다.
- **단계**: 속도와 단계 시간을 정해 순서대로 올립니다. 단계 사이에 30초 쉽니다.
- **중단 규칙**: 정상이 아닌 응답이 한 번이라도 나오거나 응답이 5초를 넘으면 즉시 멈춥니다.
- **재실행 제한**: 토큰 발급이 거절되면 표식 파일을 지우기 전까지 다시 실행하지 않습니다. 이상 응답으로 멈추면 쉬는 시간(기본 10분, `--cooldown-minutes`로 변경)이 지나기 전까지 실행하지 않습니다. 10분은 근거 없이 정한 값이고 R024는 3분으로 돌렸습니다.
- **측정**: 단계별 계획·전송·응답·정상 건수, 평균·최대 응답 시간, 처음 나온 이상 응답의 헤더, 응답이 없을 때는 예외 원인 사슬.
- **기록하지 않는 것**: 시세 값, 종목 코드, 서버 주소, 제공자 고유 코드, 키와 토큰. 원본 결과 파일은 `data/`(gitignore 대상)에만 둡니다.

## 한계
- 관측한 한도가 제공자의 공식 수치(결과 문서의 "제공자 답변")와 맞지 않아, 결과는 이 기기에서 관찰한 값으로만 읽습니다.
- 한 종목만, 장 마감 후 저녁에, 가장 길게 5분을 쟀습니다. 다른 종목, 장중, 하루 종일 유지되는지는 확인하지 않았습니다.
