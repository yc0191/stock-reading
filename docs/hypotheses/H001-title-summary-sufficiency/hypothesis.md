# H001: 제목과 요약만으로 95% 이상 정확한 맥락 판단이 가능한가

- 상태: **초안** (아래 "확정할 항목" 5개가 정해지면 확정). 기계가 읽는 정의는 [`hypothesis.toml`](hypothesis.toml)이며, 기준을 모두 정해 `state = "active"`로 올리기 전에는 루트 README에 노출되지 않는다.
- 기록일: 2026-10-22
- 관련: [ADR-007](../../adr/007-outbound-only.md) (LLM에는 공개성 정보만), [ADR-010](../../adr/010-event-format.md) (이벤트 형식, `news.collected`가 이 입력의 출처)

## 배경
뉴스 검색 API는 기사 **제목과 요약 일부**만 준다(본문 없음). 본문을 자동으로 수집하는 것은 해당 사이트의 `robots.txt`가 막고 있다(2026-10-22 확인). 그래서 뉴스 선별 단계의 LLM은 제목과 요약만 볼 수 있고, 그것으로 충분한지 모른다.

예비 관찰(검증이 아니라 가설의 동기): 종목명으로 최신 기사 20건을 조회했을 때, 제목에 검색어가 있는 기사는 1건뿐이었다. 한편 시황 기사 제목에는 원인이 적힌 경우가 있었다. 20건은 표본이라 일반화할 수 없다.

## 가설 (초안 문장)
> 뉴스 검색 결과의 **제목과 요약만** 입력으로 주었을 때, 가격 변동의 근거 후보를 고르는 세 가지 판단(J1 관련성, J2 범위, J3 원인 진술 여부)에서, 모델이 **답을 낸 항목의 정확도가 95% 이상**이다(95% 신뢰하한 기준). 이때 모델이 답을 낸 비율(**커버리지**)은 **C 이상**이다.

"어디까지 가능한가"는 정확도와 커버리지의 관계로 측정한다. 모델이 확신하지 못하는 항목을 "판단 불가"로 넘기면 정확도는 오르고 커버리지는 내려간다. 가설은 이 교환에서 정확도 95%를 지키면서 커버리지 C를 확보할 수 있는지를 묻는다.

## 용어와 판단 정의
**입력(모델이 보는 것)**: 기사의 `title`, `summary`, `publishedAt`, `publisher`와, 변동 대상(종목 이름, 변동 방향, 변동 시각). **본문은 보지 않는다.**

| 판단 | 질문 | 값 |
|---|---|---|
| **J1 관련성** | 이 기사가 대상 종목(또는 그 기초자산·섹터·시장 전반)의 가격 변동 맥락과 관련 있는가 | `related`, `unrelated` |
| **J2 범위** | 기사가 다루는 영향 범위 | `stock`(종목 단독), `sector`(업종·테마), `market`(시장 전체), `none` |
| **J3 원인 진술** | 기사가 가격 또는 지수 움직임의 **이유를 명시적으로 서술**하는가 | `yes`, `no` |

모델은 각 판단에서 위 값 외에 `abstain`(판단 불가)을 낼 수 있다.

**정답(gold)의 기준**: 사람이 **기사 전문을 읽고** 붙인 라벨이다. 모델은 제목과 요약만 보므로, 이 비교가 "전문 없이 충분한가"를 정확히 잰다. 참고로 사람이 제목과 요약만 보고 붙인 라벨도 함께 기록해, 정보 부족 자체가 만드는 한계(사람의 상한)를 구분한다.

**시간 인과는 평가 대상이 아니다.** "변동 시각 이전에 발행되었는가"는 코드(`evidence.py`)가 판정하므로 데이터셋에는 변동 이전 기사만 넣는다.

## 지표와 판정 기준 (제안)
- **정확도(답을 낸 항목 기준)** = 모델이 gold와 일치한 수 / 모델이 `abstain`하지 않은 수. 판단(J1~J3)마다 따로 계산한다.
- **커버리지** = `abstain`하지 않은 수 / 전체 수
- 보조: 판단별 혼동행렬, 오류 유형 분류, 층(stratum)별 정확도, 정확도-커버리지 곡선(모델이 확신도를 내는 경우)

**통과 조건(판단별)**: 정확도의 **단측 95% 신뢰하한이 95% 이상**이고, 커버리지가 C 이상. 신뢰구간은 정확 이항(Clopper-Pearson) 기준이다.

표본 수와 통과 조건의 관계(목표 정확도 95%, 단측 95% 신뢰, 계산 결과):

| 답을 낸 항목 수 n | 통과하려면 허용되는 최대 오답 수 |
|---|---|
| 59 (오답 0개일 때의 최소 표본) | 0 |
| 100 | 1 |
| 150 | 2 |
| 200 | 4 |
| 300 | 8 |
| 400 | 12 |

이 기준이 얼마나 엄격한지(통과 확률): 모델의 실제 정확도가 97%일 때 n=100이면 통과 확률이 약 19%, n=200이면 약 28%다. 실제 정확도가 99%여야 n=200에서 약 95%로 통과한다. 즉 **95%를 "증명"하려면 모델이 실제로는 99% 안팎이어야 하고**, 97% 수준이면 표본을 크게 늘려야 한다. 이 때문에 판정 결과는 세 가지로 나눈다.

| 결과 | 조건 | 의미 |
|---|---|---|
| **지지됨** | 신뢰하한 ≥ 95% 그리고 커버리지 ≥ C | 제목과 요약으로 충분 |
| **판정 보류** | 관측 정확도 ≥ 95%이나 신뢰하한 < 95% | 표본을 늘려 재측정 |
| **기각됨** | 관측 정확도 < 95% 또는 커버리지 < C | 대안(전문, 구조화 데이터 등) 검토 |

## 확정할 항목 (결정 필요)
1. **C (최소 커버리지)**: 제안 **60%**. 낮으면 "대부분 판단 불가"인 모델도 통과하므로 의미가 없고, 너무 높으면 95%와 동시에 달성하기 어렵다. 근거가 있는 값이 아니라 출발점이다.
2. **전체 통과 조건**: J1~J3를 모두 요구할지. 제안: **J1과 J3가 통과해야 H001 지지**, J2는 참고. 브리핑이 근거 후보를 고르는 데 필요한 것이 관련성과 원인 진술이기 때문이다.
3. **정답 라벨러**: 현재는 한 명뿐이다. 제안: 라벨의 20%를 **7일 이상 간격**으로 다시 붙여 자기 일치도(Cohen's kappa)를 보고한다. 낮으면 라벨 정의가 모호하다는 신호다.
4. **데이터셋 저장 위치**: 제안: 저장소의 `data/`(`.gitignore` 대상, 로컬 전용). 실제 종목과 기사 제목·요약이 들어가므로 커밋하지 않는다. 단, 기사 검색 결과는 시간이 지나면 다시 받을 수 없어 **로컬 복사본이 유일한 원본**이다. 백업 방법이 필요하다.
5. **평가할 모델**: 아직 정하지 않았다. 정한 뒤에는 모델과 프롬프트 버전을 고정해 기록한다.

## 위협 요인 (결과 해석 시 주의)
- **표본 편향**: 수집한 기간의 시장 국면(급락기 등)에 쏠릴 수 있다. 층화 표집으로 완화하되 한계로 보고한다.
- **정답의 주관성**: "원인을 서술하는가"는 사람마다 다를 수 있다. 라벨 정의를 문서로 두고 자기 일치도로 관리한다.
- **튜닝에 의한 과적합**: 프롬프트를 판정 데이터에 맞춰 고치면 정확도가 부풀려진다. dev/test를 분리하고 test는 확정한 구성으로 한 번만 돌린다.
- **다중 비교**: 여러 구성을 시도해 가장 좋은 것만 보고하면 통과가 쉬워진다. 시도한 모든 구성을 보고한다.
- **일반화**: 이 데이터는 한국어 시황 기사와 현재 검색어에 한정된다. 다른 종목군이나 시장 국면으로 확장하려면 다시 측정한다.
