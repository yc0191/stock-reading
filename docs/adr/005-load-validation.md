# ADR-005: 부하 검증은 실제로 발생하는 부하 지점 중심으로, 시뮬레이션임을 명시한다

- 상태: **확정**
- 기록일: 2026-10-20

## 맥락
실서비스 트래픽(특정 종목, 시간별 브리핑)은 작다. 그러나 외부 API 한도, 대량 재처리, 급변동 시 호출 폭주 같은 **실제 부하 지점**은 존재한다.

## 결정
- 부하 검증 대상은 다음 세 가지로 한다.
  1. 외부 API 호출 한도 제어(레이트 리미터, 큐, 캐시, 재시도와 백오프)
  2. 리플레이·백필 처리량(병렬성, 컨슈머 확장, 비용 제어)
  3. 급변동 시 브리핑 버스트(큐 적체, LLM 동시성 제한, 백프레셔)
- 시뮬레이터는 실제 수집기와 **같은 토픽·스키마로 발행**해 같은 코드 경로를 검증한다.
- 결과는 "시뮬레이션 기반"으로 정직하게 표기하고, **병목 분석과 튜닝 전후 수치**를 함께 남긴다.

## 후속
목표 수치(SLO)는 부하테스트 설계 단계에서 정한다. 서버 2대·단일 브로커라 절대 수치는 작을 수 있고, 중요한 것은 병목을 찾아 개선하는 과정이다.
