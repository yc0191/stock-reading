# ADR-011: 1차 알림 채널은 이메일(AWS SES)로 한다

- 상태: **초안** (실제 발송까지 검증됨, 운영 세부는 미정)
- 기록일: 2026-10-20

## 맥락
브리핑을 받아 볼 채널이 필요하다. 서버는 외부 접속을 받지 않는 아웃바운드 전용이다(ADR-007).

## 고려한 대안
Gmail SMTP, 카카오톡 "나에게 보내기"

## 결정
이메일을 AWS SES의 SMTP 인터페이스로 발송한다. 발송기는 채널을 교체·추가할 수 있는 구조(`MailSenderPort`)로 둔다.

## 이유
1. 아웃바운드 전용 방침과 완전히 맞는다.
2. 길이 제한이 없어 원인 설명과 근거 링크를 충분히 담을 수 있다.
3. AWS 계정·배포 계획과 일관된다.

## 다른 후보에 대한 판단
- 카카오톡 나에게 보내기: 즉시성이 필요해지면 2차 채널. 본인에게만 발송 가능, 액세스 토큰 약 6시간·리프레시 토큰 약 2개월, 텍스트 템플릿 200자 제한(2차 자료 기준).
- Gmail SMTP: 앱 비밀번호가 서버에 저장되어 유출 시 영향이 커서 제외.

## SES 제약과 요금
- 샌드박스에서는 발신·수신 주소가 모두 인증되어야 하고 하루 200통·초당 1통 제한이다.
- 요금(공식 페이지): Essentials 플랜은 월 고정요금 없이 1,000통당 $0.16, 이 프로젝트의 상한(시간당 6통)에서는 월 1달러 미만.

## 구현 단계에서 확인할 사항
재시작 중복 방지(현재 메모리 기반), 한도 초과분의 처리(현재는 버림).
