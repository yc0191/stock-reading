# ADR-011: 1차 알림 채널은 이메일(AWS SES)로 한다

- 상태: **확정** (구현·운영 발송 확인)
- 기록일: 2026-10-20

## 맥락
기준 3(대안이 둘 이상): 브리핑을 받아 볼 채널이 필요하고, 서비스는 외부 접속을 받지 않는다(ADR-007).

## 고려한 대안
Gmail SMTP, 메신저 "나에게 보내기"

## 결정
이메일을 AWS SES의 SMTP 인터페이스로 보낸다. 발송기는 채널을 바꾸거나 더할 수 있게 `MailSenderPort` 뒤에 둔다.

## 이유
1. 아웃바운드 전용 방침과 맞는다.
2. 길이 제한이 없어 원인 설명과 근거 링크를 충분히 담는다.
3. 배포하는 클라우드와 같은 계정에서 관리한다.

## 다른 후보
- 메신저: 본인에게만 보낼 수 있고 토큰 갱신과 글자 수 제한이 있어, 즉시성이 필요해지면 2차 채널로 본다.
- Gmail SMTP: 앱 비밀번호를 서버에 두어야 해 유출 때 영향이 커서 제외했다.

## 감수하는 점
- 요금은 발송량 기준으로 월 1달러 미만이다(SES 공식 요금 페이지 기준).
- 재시작 때 중복 방지는 메모리 기반이라 재시작 직후 같은 메일이 다시 갈 수 있다.
- 같은 종목 급변동의 반복은 발송기가 아니라 시세처리기의 종목별 재발행 간격이 막는다.
