# ADR-010: 이벤트는 JSON으로 주고받고, 스키마는 언어 중립 파일로 관리한다

- 상태: **초안** (구현됨, 세부는 계속 검토)
- 기록일: 2026-10-20

## 맥락
기준 2(여러 서비스가 함께 지키는 규칙): Java 서비스와 Python 서비스가 같은 이벤트를 읽고, 과거 이벤트를 리플레이로 다시 읽어야 한다(ADR-003). 내부 조회 API의 요청·응답 본문도 같은 스키마 파일을 계약으로 쓴다.

## 고려한 대안
Avro + 스키마 레지스트리, Protobuf

## 결정
- 직렬화는 **JSON**.
- 이벤트 형식은 `contracts/events/*.schema.json`에 **언어 중립 스키마 파일**로 정의하고, 과거 이벤트 예시는 `contracts/events/samples/`에 둔다.
- 서비스는 DTO를 직접 쓰고, **계약 테스트**로 스키마와의 일치를 검증한다.

## 이유
1. 이벤트 양이 적어 바이너리 포맷의 이점이 작고, 사람이 읽을 수 있는 편이 낫다.
2. 스키마 레지스트리 컨테이너를 늘리지 않는다.
3. Python 서비스가 Java 라이브러리를 쓸 수 없으므로 계약은 언어 중립 파일이어야 한다.

## 호환 규칙 (리플레이 보장)
- 필드는 선택 항목으로만 추가한다. 필수 필드 추가, 삭제, 타입·뜻 변경은 새 버전(`schemaVersion`)으로 낸다. 옛 버전 스키마와 샘플은 지우지 않는다.
- 소비자는 모르는 필드를 무시한다.
- 과거 이벤트 샘플이 현재 스키마와 소비자 코드로 읽히는지 테스트한다.

## 근거 조회 규칙
근거 조회는 자료를 가진 서비스의 내부 조회 API와, 조회해도 되는 때를 알리는 이벤트(뉴스처리기의 저장 끝 `news.stored`, 수집기의 판 시작 알림 `daily.collection.completed`)로 한다. 조회의 요청·응답 본문 모양은 옛 요청·응답 이벤트 스키마의 `payload`를 계약으로 그대로 쓴다.
- 2026-11-13 변경: Kafka 요청·응답 이벤트 다섯 쌍(시세 이력, 시장 배경, 데일리 자료, 기사, 공시)을 내부 조회 API(HTTP)로 바꿨다(ADR-006). 그 토픽은 선언·발행·구독을 모두 없앴고, 스키마·샘플은 설명에 '더 이상 쓰지 않음'을 붙여 남긴다(위 호환 규칙). 수집기의 수집 완료(`collection.completed`)에 이번 작업에서 보낸 기사 이벤트 id 목록(`articleEventIds`)을 싣고, 뉴스처리기는 그 기사가 모두 처리되면(또는 대기 한도에) 저장 끝(`news.stored`, 처리 결과별 건수와 끝내 처리되지 않은 id 포함)을 낸다. 브리핑은 저장 끝을 받은 뒤 기사를 한 번만 조회하며, 같은 저장 끝은 `eventId`로 한 번만 처리한다. 예전처럼 기사를 여러 번 다시 조회해 목록이 안정됐는지 추측하지 않는다.
- `jobId`는 작업을 시작시킨 이벤트(`market.move` 또는 판 시작 알림 `daily.collection.completed`)의 `eventId`다. 알림 없이 한도 시각에 시작한 데일리 판은 판과 날짜로 정한 id를 쓴다.
  - 2026-11-13 변경: 데일리 판은 수집기의 판 시작 알림(`daily.collection.completed`)으로 시작한다(ADR-012).
- `seq`는 작업 안의 조회 순번이다. 응답은 받은 `jobId`·`seq`를 돌려주어 양쪽 로그와 작업 기록에서 같은 조회를 찾게 한다.
- 조회는 읽기 전용이라 다시 불러도 부작용이 없고, 0건 응답도 정상이다.
- 기존 응답의 뜻을 바꾸지 않도록, 새 자료는 기존 응답에 얹지 않고 새 조회로 더한다.

## 겪은 함정
- `OffsetDateTime.toString()`은 초가 0이면 초를 생략해 RFC 3339 `date-time`에 어긋난다. 표준 포매터를 쓴다.
- JSON 스키마 검증 라이브러리는 `date-time` 같은 형식을 기본으로 검사하지 않는다. 형식 검사를 켜고, 잘못된 입력이 실제로 거부되는지 음성 테스트로 확인한다.

## 감수하는 점
형식 강제를 서버(레지스트리)가 아니라 테스트와 규칙으로 지켜야 한다.
