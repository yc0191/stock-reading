# ADR-014 경위

[ADR-014](../014-ops-checker.md)의 결정이 바뀐 경위입니다(날짜순). ADR 본문에는 현재 결정만 있습니다.

- 2026-11-19 변경: 확인기의 결과 파일 쓰기를 서버 계정 권한에서 쓰기 전용 사용자로 옮겼다. 설정 읽기·메일 발송·ECR 받기까지 되는 서버 계정 키를 확인기 컨테이너에 넣지 않고, 키가 새도 결과 파일 올리기 말고는 할 수 없게 권한을 줄이기 위해서다.
- 2026-11-20 변경: 판정이 끝나면 `check-passed`/`check-failed` 라벨을 붙이던 것을 없애고, 통과·실패는 최종 댓글에만 남기고 `verifying`만 뗀다. 라벨이 이미 많아 결과를 라벨로 한 번 더 나타낼 필요가 없어서다.
