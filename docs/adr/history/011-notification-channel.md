# ADR-011 경위

[ADR-011](../011-notification-channel.md)의 결정이 바뀐 순서입니다. 본문에는 현재 결정만 둡니다.

- 2026-10-20: AWS SES SMTP로 보내기로 했다. 메일 서비스 자체 SMTP는 앱 비밀번호를 서버에 두어 유출 때 영향이 크다고 보고 제외했다.
- 2026-11-18: 메일 서비스의 발송 전용 계정 SMTP로 바꿨다. 무료 메일 주소를 SES로 보내면 DMARC가 실패해 모든 메일에 경고가 붙었다(#82). 앱 비밀번호 위험은 개인 계정이 아닌 발송 전용 계정만 써서 줄인다.
