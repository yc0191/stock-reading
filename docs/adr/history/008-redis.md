# ADR-008 경위

[ADR-008](../008-redis.md)의 결정이 바뀐 경위입니다(날짜순). ADR 본문에는 현재 결정만 있습니다.

- 2026-11-12 변경: 서버 한 대·수집기 하나인 지금은 도입하지 않는다. 메모리 안 호출 상한이 정확하고, 컨테이너를 늘리지 않는다. 여러 인스턴스가 될 때 도입한다.
- 2026-11-27 변경: 도입한다. 재검색이 최근 검색 결과를 다시 쓰려면 재시작해도 남고 인스턴스끼리 함께 쓰는 캐시와 만료가 있는 검색 중 표시가 필요해, 수집기 최근 검색 보관소를 Redis로 옮겼다(#98 후속). 두는 것을 잃어도 되는 것으로 한정하고 키·만료·운영 규칙을 정했다.
