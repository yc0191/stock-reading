# ADR-007: 외부에서 들어오는 접속 없이 아웃바운드 전용으로 시작한다

- 상태: **확정**
- 기록일: 2026-10-20

## 맥락
기준 1(되돌리기 어려운 선택): 외부 노출 여부는 인증·배포 구성을 모두 바꾼다. 공개 입구는 그 자체로 공격 대상이 된다.

## 결정
- 서비스는 **외부 접속을 받지 않는다**. 밖으로 나가는 호출(시세·뉴스 API, LLM, 이메일)만 한다.
  2026-11-13 변경: 관리 접속은 Lightsail 콘솔의 브라우저 SSH에서만 받고, 두 서버끼리는 사설 주소로만 통신한다([ADR-013](013-lightsail-compose-deploy.md)).
  - 2026-11-13 변경: 시세처리기·뉴스처리기가 서비스 간 내부 조회(HTTP)를 같은 컨테이너 네트워크 안에서만 받는다. 서버 밖 포트는 열지 않는다(원본: `infra/deploy/compose/services.yml`).
- 정기 브리핑을 생성해 **보내는 것**까지 하고, 질의 기능은 두지 않는다.
- 외부 입구를 열 때는 이 ADR을 먼저 갱신하고 인증 방식을 정한다.

## 원칙 (나중에 LLM 질의를 열 때)
1. 연산은 LLM이 아니라 코드가 한다. 도구는 계산된 값을 돌려준다.
2. 인증은 코드가 한다. LLM의 판단에 맡기지 않는다.
3. 도구는 읽기 전용으로 시작한다.
4. LLM에는 공개성 정보(가격 변동, 뉴스 제목·요약)만 주고, 개인 정보는 코드가 최종 메시지에 직접 넣는다.
