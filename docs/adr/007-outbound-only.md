# ADR-007: 외부에서 들어오는 접속 없이 아웃바운드 전용으로 시작한다

- 상태: **확정**
- 기록일: 2026-10-20

## 맥락
공개 엔드포인트는 입구 자체가 공격 시도를 받는다.

## 결정
- 서버는 **외부 접속을 받지 않는다**(보안그룹으로 인바운드 차단). 밖으로 나가는 호출(증권사·뉴스 API, LLM, 이메일)만 한다.
- 시작 단계(α)는 정기 브리핑을 서버가 생성해 **발송하는 것**까지다. 질의 기능은 없다.
- **인증 없는 접근은 전부 거부**한다. 인증 방식은 외부 입구를 여는 시점에 정한다.

## 단계적 확장
| 단계 | 내용 | 공개 노출 |
|---|---|---|
| α (현재) | 서버가 정기 브리핑 생성·발송. 질의 없음 | 없음 |
| β (후속) | Claude Code 전용 MCP, SSH 터널로만 접속 | 없음 (추론, 구현 시 확인) |
| γ (보류) | Claude 앱(커스텀 커넥터)용 공개 엔드포인트 | **있음** (Claude 앱은 Anthropic 클라우드에서 접속하므로 공개 주소가 필요함을 문서로 확인) |

## 원칙 (LLM 질의를 열 때)
1. 연산은 LLM이 아니라 서비스(코드)가 한다. 도구는 계산된 값을 반환한다.
2. 인증은 코드(관문)가 한다. LLM의 판단에 맡기지 않는다.
3. 정기 브리핑은 LLM 질의와 별개로 서버가 발송한다.
4. 도구는 읽기 전용으로 시작한다.
5. **LLM이 보는 정보와 못 보는 정보를 구분한다.** LLM에는 공개성 정보(가격 변동, 요인, 뉴스 제목·요약)만 주고, 개인 금액·수량은 코드가 최종 메시지에 직접 넣는다.
